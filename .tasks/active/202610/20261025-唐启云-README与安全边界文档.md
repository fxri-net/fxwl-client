# README 与安全边界文档

计划位置：阶段五 收口 第 2 项；前置：三平台打包回归。

## 一、背景

改造后多处使用者的预期会变：配置从可执行文件同级迁到用户数据目录，内嵌页只允许白名单地址，主进程 IPC 不再有通用命令通道，Electron 停留在 22 是为兼容 Win7 且已停止维护。这些信息目前只存在于对话与代码里，README 仍是旧内容。

## 二、实施方案

- 开发与验收：补 `pnpm verify` 一条聚合命令的说明，替代分散脚本列举。
- 运行时基线：说明 Electron 22 与 Win7 的关系、停止维护带来的安全边界，以及主进程可用 Node 版本上限。
- 配置：说明配置目录位置变更、迁移行为与回滚方式。
- 内嵌页：说明白名单配置位置与添加方法。

## 三、影响范围

仅 `README.md`；不涉源码。

## 四、验证方式

- 文档中的命令可逐条复制执行
- 配置目录与白名单描述与实现一致
- `pnpm verify` 通过（文档改动不破坏 lint）
