# 抄录版权声明

## 一、背景

本仓版权面只有 README 一段文字与 `electron-builder.yml` 的 `copyright` 行，著作权主体写作「方弦研究所」、年份写作 2023-2099；`package.json` 的 `license` 为非 SPDX 的 `Apache2`；缺 `NOTICE` 与商标声明文件。参照同体系工具仓的版权声明体系（`NOTICE` + `TRADEMARK.md` + README 版权段 + 包与安装包元数据），按本仓协议口径 `Apache License 2.0` 补齐。

## 二、实施方案

- 新建 `NOTICE`：产品名 + `Copyright © 2023-2026 唐启云. All rights reserved.` + 出品方 + 商标声明摘要。
- 新建 `TRADEMARK.md`：照录「方弦®」商标声明，协议名按本仓写 `Apache License 2.0`。
- `README.md` 版权段：补出品、协议、商标三行与「非独立法人」注脚，版权行改自然人主体。
- `package.json`：`license` 归一为 `Apache-2.0`，`author` 由字符串改为 `{ name, email, url }` 对象。
- `electron-builder.yml`：`copyright` 同步为自然人主体与年份区间。
- `LICENSE` 正文不动。

## 三、影响范围

仅文档与包 / 安装包元数据字段；不涉源码与构建流程。⚠️ `author` 改对象后，Linux 打包的 `maintainer` 取值随 electron-builder 解析变化。

## 四、验证方式

- 检索旧口径 `方弦研究所. All rights reserved`、`2023-2099` 归零
- `package.json` 可解析且 `license` 取值为 `Apache-2.0`
- `toolkit tasks check` 0 error / 0 warn

## 五、回滚方案

提交前 `git checkout -- README.md package.json electron-builder.yml NOTICE TRADEMARK.md`；已提交则按提交哈希回退。
