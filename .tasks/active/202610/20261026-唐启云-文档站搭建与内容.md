# 文档站搭建与内容

计划位置：阶段五 收口 第 3 项；前置：变更集体系与历史 CHANGELOG 回溯。

## 一、背景

README 承载不了完整说明：运行环境、配置字段、构建与打包、内嵌页放行、安全边界、快捷键都需要一份可检索、可分层的文档。项目需要静态文档站，并能从仓库根更新日志同步生成更新日志页，避免文档与实际发布脱节。

## 二、实施方案

- 用 VitePress 搭静态站点：基址、站点地址、仓库地址经环境变量注入，同一份源码可同时部署到两条托管链路（发布链路见 CI 双平台接入任务）。
- 页面规划八页：首页、快速开始、使用手册、配置说明、开发指南、构建与打包、常见问题、更新日志。
  - 首页：定位与能力概览，给出最短上手路径。
  - 快速开始：环境要求、安装与首次启动、旧配置迁移结果。
  - 使用手册：首页配置、内嵌页操作、悬浮导航胶囊、快捷键与鼠标侧键。
  - 配置说明：逐项解释配置字段、默认值与生效方式。
  - 开发指南：目录结构、契约分层、状态三分、验收命令。
  - 构建与打包：三平台产物、Electron 版本基线与 Win7 约束。
  - 常见问题：迁移、白名单、快捷键、退出残留等高频疑问。
- 安全边界内容（版本维护状态、IPC 白名单、内嵌页放行、外链与权限策略）并入开发指南与常见问题，不单独成页。
- 更新日志页由脚本从仓库根 `CHANGELOG.md` 生成，保持单一真源；脚本做编码与行尾归一，并校验源文件结构。
- 视觉：复用项目设计令牌与品牌色，图标与社交分享图取自仓库已有静态资源；开启最后更新时间、站内搜索与站点地图。

## 三、影响范围

新增 `docs/` 目录与更新日志同步脚本；`package.json` 增加文档开发 / 构建 / 预览脚本与 VitePress 依赖。不改运行时代码。

## 四、验证方式

- `pnpm docs:build` 可构建，本地预览下首页与七个子页可跳转，侧边栏与站内搜索可用
- 更新日志页与仓库根 `CHANGELOG.md` 一致（同步脚本重复执行零差异）
- `pnpm verify` 通过

## 五、回滚方案

删除 `docs/` 与同步脚本，还原 `package.json`；已提交则按提交哈希回退。
