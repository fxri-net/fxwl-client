# 路由数据化与守卫

计划位置：阶段三 渲染层 第 4 项；前置：单源持久化桥接。

## 一、背景

`router/index.ts` 用 `$.each(routes.reverse())` 反推 base，路由顺序变化会改变 base 结果；初始化重定向写在 `afterEach` 里并现场调用 `useRouter()`，属于在收尾钩子里发起导航，重复触发与竞态都会出现。

## 二、实施方案

- 路由表改为数据化声明，每项含 `path`、组件与 `meta`（标题、是否需要初始化）。
- base 改由环境配置显式给出，不再从路由表反推。
- 初始化重定向迁入 `beforeEach`，命中即 `return` 目标路径。
- `afterEach` 只保留标题设置等收尾动作。

## 三、影响范围

路由定义与导航钩子；页面路径保持不变。⚠️ 守卫内不得依赖组件实例或 store 的挂载时机，需在守卫内按需获取实例。

## 四、验证方式

- 首次启动重定向只触发一次
- 深层路由直接刷新落到正确页面
- `pnpm verify` 通过

## 五、回滚方案

`git checkout -- src/renderer/src/router`；已提交则按提交哈希回退。
