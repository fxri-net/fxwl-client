# 公共组件抽取

计划位置：阶段三 渲染层 第 5 项；前置：路由数据化与守卫。

## 一、背景

首页与配置页各自复制了一份「刷新 / 清理缓存 / 重启 / 退出」四个动作及其 footer 样式；配置页内七段开关是同一个 `el-switch` 结构的重复粘贴，改一处文案要改七处。

## 二、实施方案

- `components/AppLayout.vue`：页面外壳（标题栏插槽、内容区、footer 插槽）。
- `components/ActionBar.vue`：四个全局动作，动作实现集中在组件内，页面只传当前可用项。
- `components/SettingSwitch.vue`：开关行，props 为标签、说明、模型值。
- `components/SettingField.vue`：标签 + 控件的通用行，供下拉与数值输入复用。
- `components/AppFooter.vue`：底部信息与版本号。
- 组件 props / emit 契约按项目既有风格命名，注释全中文。

## 三、影响范围

两个页面的模板结构；不影响 IPC 与状态。

## 四、验证方式

- 两个页面复用同一组组件，无重复样式块
- 四个动作行为与改动前一致
- `pnpm verify` 通过

## 五、回滚方案

删除新增组件并 `git checkout -- src/renderer/src/views`；已提交则按提交哈希回退。
