# 悬浮导航胶囊

计划位置：阶段四 内嵌网页宿主 第 3 项；前置：客户端视图重写。

## 一、背景

退出内嵌页的按钮是一个 160×80、平时完全不可见的隐形热区，仅在 hover 时出现 10% 白底；位置以整段内联 style 字符串存在配置里，四个角落靠拼接不同字符串实现。使用者不知道它存在，且这块不可见区域会吃掉内嵌网页左上角一大片可点击区。

## 二、实施方案

- 新增 `components/NavCapsule.vue`：包含「后退」与「退出内嵌页」两个动作，语义由此前混称的一个按钮拆开；不可后退时只显示退出。
- 位置由 `NavConfig` 驱动：`anchor` 四角枚举 + `offsetX` / `offsetY` 数值，经 `inset` 与 CSS 变量落地，配置只存语义值。
- 静态 3 秒后整体淡至 `idleOpacity`（默认 0.35），鼠标进入、键盘聚焦或触摸时恢复满不透明；首次进入完整显示 3 秒作一次性引导。
- 触摸目标不小于 48×48，视觉尺寸 40px 胶囊，以 padding 撑开热区。
- 过渡 160ms，`prefers-reduced-motion` 下取消动画。
- 配置页提供锚点下拉与偏移数值输入，替代原 style 字符串输入。

## 三、影响范围

客户端页叠加层与配置项结构；旧配置经 migrations 自动映射。⚠️ 原热区尺寸与位置语义改变，需确认四角偏移默认值不遮挡内嵌页自身操作区。

## 四、验证方式

- 四角切换即时生效，偏移数值生效
- 空闲淡出与悬停恢复符合预期，触摸设备可点
- 旧 style 字符串配置迁移后位置正确
- `pnpm verify` 通过

## 五、回滚方案

删除组件并还原配置项，旧配置目录保留可回退；代码侧按提交哈希回退。
