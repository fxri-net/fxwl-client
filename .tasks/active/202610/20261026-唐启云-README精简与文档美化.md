# README 精简与文档美化

计划位置：阶段五 收口 第 4 项；前置：文档站搭建与内容。

## 一、背景

README 仍是旧版本号与命令罗列，并承担了过多技术细节；文档站落地后，README 只应保留定位、能力、获取方式与文档入口，细节统一由文档站承载。

## 二、实施方案

- 重写 README 结构：项目定位、能力矩阵、运行环境、下载与安装、文档站入口、界面截图、更新日志入口、版权与商标声明。
- 移除技术细节（配置字段、目录结构、安全边界、构建命令枚举），改为指向文档站对应页面。
- 视觉统一：品牌色与分隔结构，补 CI 状态、当前版本、Win7 支持、许可协议徽章；截图与图标取自仓库已有资源。
- 校对与文档站的双向链接，确保无死链、无失效锚点。

## 三、影响范围

仅 `README.md`；不改源码与构建产物。

## 四、验证方式

- README 全部链接可打开
- 不再出现配置字段、目录结构、安全策略等技术细节
- 版本号与徽章信息与实际一致

## 五、回滚方案

`git checkout -- README.md`；已提交则按提交哈希回退。
