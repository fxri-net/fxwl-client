# 视图与样式重写

计划位置：阶段三 渲染层 第 6 项；前置：公共组件抽取。

## 一、背景

配置页约 285 行，绝大部分是重复的开关块与行内样式；位置类配置以整段 style 字符串存储在 store 中，配置项形状不可校验；样式分散在 `styles/base.scss` 与各组件内，无统一设计变量，改主色要逐处替换。

## 二、实施方案

- 重写 `views/index/Index.vue` 与 `views/index/Config.vue`，配置项按 schema 驱动渲染，新增配置只需在 schema 与渲染映射各加一处。
- 新增 `styles/tokens.scss`：颜色、圆角、间距、动效时长以 CSS 变量声明。
- 覆盖 Element Plus 主题变量，使组件默认色与令牌一致。
- 清理无效样式与重复选择器，`base.scss` 只保留全局基础规则。

## 三、影响范围

两个视图的结构与全站样式来源；页面功能不变。⚠️ 配置项名称与 schema 键一一对应，迁移期需同时核对旧配置读取路径。

## 四、验证方式

- 配置页行数明显下降，配置项与 schema 完全对应
- 主色修改只需改一处令牌
- 三页视觉回归无明显差异
- `pnpm verify` 通过

## 五、回滚方案

`git checkout -- src/renderer/src/views src/renderer/src/styles`；已提交则按提交哈希回退。
