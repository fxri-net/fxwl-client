# 适配 Windows 7 打包运行（Electron 降级至 22.3.27）

## 背景

`pnpm build:win` 产出的安装包在 Windows 7 上无法启动。根因是 Electron 版本本身不支持该系统：项目锁定 `electron ^41.0.0`（实装 41.10.4，Chromium 146 / Node 24），而 Electron 23（Chromium 110）起官方已终止 Windows 7/8/8.1 支持，Electron 22 是最后一个支持这三个系统的大版本。

目标机为 64 位 Windows 7，打包维持默认 x64 nsis 目标即可，无需额外声明架构。

## 实施方案

1. `package.json`：`electron` 由 `^41.0.0` 改为精确版本 `22.3.27`（22.x 最终版，Chromium 108 / Node 16.17.1 / V8 10.8）。使用精确版本避免解析到 23+ 丢失 Win7 支持。
2. `electron-builder.yml`：无需改动。`win` 未声明 `target` 时默认即 nsis + 宿主机架构，本机为 x64，产物名称维持 `${description}-${version}.${ext}`。
3. `pnpm install --no-frozen-lockfile`：重装依赖并替换 `node_modules/electron` 内的 41 版二进制。两步注意点：锁文件与 manifest 不一致时 `frozen-lockfile` 会直接报错；Electron 二进制默认走 GitHub 下载，本机实测长时间无进展，需加环境变量 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/` 走 npmmirror 镜像（实测 36.9s 完成）。
4. `pnpm build:win` 验证产物。electron-builder 下载 Electron 与 nsis 二进制同样受网络影响，打包时一并设置 `ELECTRON_MIRROR` 与 `ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/`。

`electron.vite.config.ts` 无需改动：`electron-vite@5` 内置 Electron 版本映射（`getElectronNodeTarget` / `getElectronChromeTarget`），对 `22` 自动取 `node16.17` 与 `chrome108` 编译目标。`bytecodePlugin` 生成的 V8 字节码会随本地 Electron 二进制重新编译，与运行时 V8 版本保持一致。

## 影响范围

- 全平台运行时同时降到 Electron 22，mac / linux 产物需一并回归。
- 开发环境 `pnpm dev` 也运行在 Electron 22，主进程仅可使用 Node 16.17 支持的语法。
- 主进程外部化依赖已核查兼容：`electron-store@8.2.0` 为 CJS，`http-server`、`@electron-toolkit/utils`（peer `electron >=13.0.0`）、`@electron-toolkit/preload`（同）均支持 Node 16。
- 主进程代码仅使用 `app` / `BrowserWindow` / `ipcMain` / `dialog` / `shell` 等老 API，无 Electron 23+ 移除项，类型定义降级不产生破坏。
- 安全：Electron 22 已于 2023-10-10 EOL，此后 Chromium 层漏洞不再修复，属保留 Win7 支持的固有代价。

## 验证方式

1. `pnpm build` 通过 node 与 web 两侧 typecheck。
2. 产物启动后确认运行版本为 `electron 22.3.27`、`chrome 108.x`。
3. 在 32 位 Windows 7 SP1 实机或虚拟机完成冒烟：启动、窗口创建、配置页读写、HTTP 服务开关、开机自启。
4. 目标机前置条件：Windows 7 SP1 及补丁 KB2533623、KB4474419、KB4490628，缺失时表现为启动即闪退。

## 实施结果

- `pnpm install --no-frozen-lockfile` 36.9s 完成，`node_modules/electron` 实装 `22.3.27`，`node_modules/electron/dist/electron.exe` 文件版本 22.3.27。
- `pnpm build:win` 通过（node / web 两侧 typecheck 均无报错），产出 `dist/方弦物联：桌面终端-1.0.1.exe`，PE 机器类型 `0x8664`（x64），体积 76MB。
- 启动冒烟：运行 `dist/win-unpacked/fxwl-client.exe`，进程存活 10s、占用 153MB，未发生启动即退。
- 目标机 Win7 实机冒烟未做，需交付前在 64 位 Windows 7 SP1 上验证。

## 已知问题与兜底

- Win7 启动白屏时，在 `src/main/index.ts` 追加 `app.disableHardwareAcceleration()` 或 `--disable-gpu`（老显卡驱动常见）。
- 进程无法拉起时追加 `--no-sandbox`。
- 若 `bytecodePlugin()` 产出的字节码在 Electron 22 下加载异常，先临时移除该插件定位。

## 回滚方案

`git checkout package.json pnpm-lock.yaml` 后执行 `pnpm install`，即退回 Electron 41 基线（要求 Windows 10 及以上）。
