# 使用手册

本页面向日常使用：页面怎么走、配置怎么改、内嵌页怎么操作。

## 一、页面结构

应用只有三个页面，全部经 hash 路由跳转：

| 页面 | 入口 | 用途 |
| --- | --- | --- |
| 首页 | 启动默认进入 | 卡片式入口，跳转到配置项与客户端 |
| 配置项 | 首页卡片 / 地址 `#/config` | 应用、面板、客户端三组配置 |
| 客户端 | 首页卡片 / 地址 `#/client/index` | 内嵌网页展示页 |

窗口标题由「页面名 - 应用标题」组成，应用标题取「配置项 → 应用 → 应用标题」。

## 二、底部动作栏

首页与配置页底部固定一条动作栏，高度 52px。

| 动作 | 行为 |
| --- | --- |
| 刷新页面 | 先把待写入的配置立即落盘，再重载整个界面 |
| 清理缓存 | 清空页面参数与临时部署数据后刷新界面 |
| 返回首页 | 回到首页 |
| 重启应用 | 二次确认后重启进程，用于让重启类配置生效 |
| 退出应用 | 二次确认后退出进程 |

::: tip 为什么动作前要先落盘
配置改动是防抖写入的（约 0.5 秒）。刷新、重启、退出都会打断界面进程，动作执行前会强制把待写入内容落盘，避免最后几次修改丢失。
:::

## 三、配置页

配置页由配置 schema 驱动渲染，共三个页签：

- **应用**：应用标题、调试模式、默认页面
- **面板**：窗口配置（尺寸、位置、全屏、无边框、置顶、强制置顶、开机自启、HTTP 缓存）与网站配置（静态服务开关、目录、端口、端口占用提示）
- **客户端**：页面地址、导航位置、水平与垂直偏移

页签栏右端显示当前版本号，便于排查时确认现场运行的是哪一版。

控件的写法由字段类型决定：文本框、开关、下拉框、目录选择。选择目录会弹出系统目录选择框，取消时保持原值。

每个页签底部有「重置选项」，动作栏左侧有「全部重置」：重置会把对应范围恢复为出厂默认值，落盘后刷新界面。

## 四、客户端页

客户端页把配置的网页嵌进窗口，并处理三种状态：

| 状态 | 呈现 |
| --- | --- |
| 未配置 | 提示尚未配置客户端地址，并指引去「配置 - 客户端」填写 |
| 加载中 | 显示加载指示 |
| 加载失败 | 显示错误描述、错误码与目标地址，提供「重试」与「返回首页」 |

重试是就地重载，保留会话与浏览历史；返回首页销毁内嵌页。

加载指示在页面文档就绪时即撤除，图片等资源仍在后台继续加载，不会挡住已可操作的页面。

::: details 哪些失败不会提示
子框架加载失败不影响整体展示，直接忽略。错误码 `-3` 表示导航被主动取消（例如跳转被拦截），同样不提示。
:::

## 五、悬浮导航胶囊

内嵌页左上、右上、右下、左下四个位置可停靠导航胶囊，水平与垂直偏移各支持 0～400 像素。

- 默认停靠左上角，偏移为 0。
- 平时完全隐藏，展示内容之外不占任何可见元素；鼠标移入贴边热区（胶囊区域四周各外扩 10 像素）或键盘聚焦时显现，鼠标移出即刻隐藏。
- 胶囊为深色半透明直角底、白字，压在内嵌页与视频之上也保持可读。
- 进入客户端页不显示胶囊，只有热区与键盘聚焦能唤起它。
- 只有内嵌页存在可后退历史时才显示「后退」按钮。
- 「返回首页」按钮销毁内嵌页并回到首页。
- 用快捷键触发后退时，胶囊会亮起 3 秒，提示导航仍在原位置。

## 六、快捷键与鼠标侧键

| 操作 | 行为 |
| --- | --- |
| `Alt + ←` | 内嵌页后退 |
| `Esc` | 内嵌页可后退时后退；已在起始页时返回首页 |
| 鼠标侧键 | 内嵌页后退 |

焦点落在网页内部时，宿主界面收不到键盘事件，因此这些按键由主进程监听内嵌页后转发给界面执行。

::: warning Esc 的两处例外
- 焦点在输入框、文本域、下拉框或可编辑区域时，`Esc` 交还网页处理。
- 网页处于全屏元素状态时，`Esc` 同样交还网页，用于退出网页自身的全屏。
:::

## 七、展示行为

以下开关在「配置项 → 面板 → 窗口配置」中：

| 配置 | 效果 | 生效时机 |
| --- | --- | --- |
| 开机自启 | 勾选即注册开机启动，取消即注销 | 勾选或取消时立即生效 |
| 全屏 | 以全屏方式打开窗口 | 下次启动 |
| 无边框 | 关闭系统边框与标题栏 | 下次启动 |
| 置顶 | 窗口保持在其它窗口之上 | 下次启动 |
| 强制置顶 | 每 300 毫秒检查一次，抢到焦点后顶到最前 | 下次启动 |
| HTTP 缓存 | 关闭后禁用 HTTP 缓存，避免展示旧页面 | 重启应用后 |

尺寸、位置在关闭窗口时自动记住（取常规状态下的边界，最大化或全屏时也能恢复到原尺寸），下次启动沿用。位置填「居中」时交由系统居中。

::: warning 强制置顶的使用场合
强制置顶会周期性抢占焦点，适合展厅、大屏等专用设备；在有键鼠交互的办公机上开启会打断正常操作。
:::

## 八、静态服务

「配置项 → 面板 → 网站配置」可让应用在本机托管一份静态站点：

- **开关**：开启后随应用启动而启动，关闭则不起服务。
- **目录**：站点根目录，相对路径按用户数据目录解析，默认 `website`。
- **端口**：默认 2602；被占用时自动向后寻找可用端口，最多尝试 100 次。
- **端口占用提示**：开启后，端口发生避让时弹框告知实际使用的端口。

客户端页的页面地址填 `http://127.0.0.1:2602`，即可展示这份本地站点。

## 九、进程行为

- 重复启动应用不会开出第二个窗口，已运行的窗口会被还原并聚焦。
- Windows 与 Linux 关闭全部窗口即退出应用；macOS 保留进程，点击 Dock 图标会重建窗口。
