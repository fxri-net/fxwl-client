# 快速开始

本页给出最短可用路径：安装、首次启动、把网页接进来。日常操作细节见[使用手册](./manual)。

## 一、运行环境

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 7 SP1 及以上、macOS、Linux（x64） |
| 内嵌页面 | `http` 或 `https` 地址，且可被本机访问 |
| 磁盘 | 安装目录 + 用户数据目录，后者存放配置与本地站点 |

::: warning Windows 7 说明
应用固定在 Electron 22 版本线——这是最后一个支持 Windows 7 的版本。该版本线已停止安全维护，因此安全边界由应用层能力收紧承担（见[开发指南](./development#安全边界)）。
:::

## 二、获取与安装

安装包随版本发布在仓库的 Releases 页面：

- [GitHub Releases](https://github.com/fxri-net/fxwl-client/releases)
- [Gitee Releases](https://gitee.com/fxri/fxwl-client/releases)

各平台产物：

| 平台 | 产物 | 说明 |
| --- | --- | --- |
| Windows | NSIS 安装包 | 可选择安装目录、默认创建桌面快捷方式，卸载入口显示为应用全名 |
| macOS | 磁盘映像 | 签名与公证由打包流程中的公证脚本处理 |
| Linux | AppImage / deb / snap | 按发行版习惯任选其一 |

安装包文件名取自打包配置的 `artifactName` 模板（`${description}-${version}.${ext}`），同名同版本重复安装会覆盖升级。

## 三、首次启动

启动后进入应用首页，默认窗口 1280 × 720，无系统边框、自动隐藏菜单栏，底部固定动作栏显示当前版本号。

首页提供两张入口卡片：

- **配置项**：应用、面板、客户端三组配置
- **客户端**：内嵌网页的展示页

## 四、最短可用路径

1. 进入「配置项 → 客户端」，在「页面地址（HTTP）」填入网页地址，例如 `http://127.0.0.1:2602`。
2. 回到首页，点「客户端」卡片进入展示页；地址未填或不是 HTTP 地址时，页面会提示尚未配置。
3. 按现场需要调整「配置项 → 面板」：窗口尺寸与位置、开机自启、全屏、置顶、强制置顶。

改动即时生效并自动落盘（约 0.5 秒），无需手动保存。若希望改成重启后才生效的项（如 HTTP 缓存），见[配置说明](./config#生效方式)。

## 五、数据目录

配置与本地站点统一落在用户数据目录，避免安装到受管控目录后不可写：

```text
<用户数据目录>/
├─ config/          # 配置目录，electron-store 读写
│  └─ config.json
├─ website/         # 默认本地站点目录，静态服务以它为根
└─ .migrated        # 迁移完成标记，存在即不再重复迁移
```

Windows 下用户数据目录默认为 `%APPDATA%\fxwl-client`，macOS 下为 `~/Library/Application Support/fxwl-client`。

「面板 → 网站配置 → 目录」填相对路径时按用户数据目录解析，填绝对路径则原样使用。

## 六、旧版本升级

旧版本把数据写在可执行文件同级的 `fxwl-local` 目录。新版本首次启动时自动迁移：

1. 若新目录与旧目录重合或旧目录不存在，直接使用用户数据目录。
2. 若已存在 `.migrated` 标记，直接使用用户数据目录，不重复复制。
3. 否则复制旧目录下的 `config` 与 `website`；目标已存在的文件不覆盖。
4. 全部复制成功后才写 `.migrated`；中途失败则回退旧目录继续启动，旧目录保持原样便于手工恢复。

::: tip 迁移失败怎么办
应用不会因迁移失败而无法启动。此时配置仍写在旧目录下，可先关闭应用，手工把 `fxwl-local` 下的 `config`、`website` 复制到用户数据目录，再启动。
:::
